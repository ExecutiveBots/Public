# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| v5.x    | :white_check_mark: |
| < 5.0   | :x:                |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue, please report it responsibly.

### Contact

**Security Email**: [security@executives.bot](mailto:security@executives.bot)

Please **do not** open a public GitHub issue for security vulnerabilities. Email us directly at the address above.

### What to Include in Your Report

When reporting a vulnerability, please include:

1. **Description**: A clear description of the vulnerability
2. **Steps to Reproduce**: Detailed steps to reproduce the issue
3. **Impact**: The potential impact of the vulnerability
4. **Scope**: What systems or data could be affected
5. **Any Suggested Fixes** (optional): If you have ideas for mitigation

## Response SLAs

We are committed to responding to security reports promptly:

| Response Stage | SLA |
|----------------|-----|
| **Initial Triage** | 24 hours |
| **Assessment & Remediation Plan** | 7 days |
| **Critical Issues** | Expedited response (contact us directly for critical vulnerabilities) |

### What to Expect After Reporting

1. **24 hours**: We will acknowledge receipt of your report and begin initial triage
2. **7 days**: We will provide an assessment of the vulnerability and, if applicable, a remediation plan
3. **Ongoing**: We will keep you informed of our progress and notify you when a fix is available

## Disclosure Policy

We follow a coordinated disclosure process:

1. Reporter notifies us via the security email
2. We acknowledge within 24 hours
3. We work on a fix with a target 7-day remediation window
4. Once the fix is ready, we coordinate disclosure with the reporter
5. Public disclosure follows after the fix is deployed

## Recognition

We believe in recognizing the contributions of security researchers. With your permission, we will add your name to our [Security Hall of Fame](./SECURITY_HALL_OF_FAME.md) (to be created) unless you prefer to remain anonymous.

## Scope

This security policy applies to:

- The ExecutiveBots V5 platform documentation repository
- Wiki skill files and agent documentation
- GitHub workflows and CI/CD configuration

For vulnerabilities in deployed production systems, contact [security@executives.bot](mailto:security@executives.bot) with details about the affected deployment.

## Legal Safe Harbor

We appreciate responsible disclosure. We commit to not pursue legal action against researchers who:
- Follow this coordinated disclosure process
- Make a good faith effort to avoid privacy violations, data destruction, and service disruption
- Provide sufficient detail to reproduce and verify the vulnerability
