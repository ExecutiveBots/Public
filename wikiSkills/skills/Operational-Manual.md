# Part I — System Overview

## §1 Purpose & Audience

### 1.1 What this manual is

This is the integrated operational reference for the ExecutiveBots V5 platform. It describes how the eight AI executive agents work, how they interact with each other and with the subscriber's Human Board of Record (HBR), what ethical values constrain their operations, what skillsets each possesses, and how the 28 canonical content files in the system relate to each other across the three-layer governance hierarchy plus the orthogonal technical-platform track.

The manual is **not** the authoritative specification of any agent's behavior — the per-agent SOUL and SKILL files are. The manual is also not the authoritative procedure for any operational workflow — the operational playbooks are. The manual synthesizes the authoritative content into a readable reference and supplies the document-architecture map that locates each authoritative source.

### 1.2 Audience

| Audience                                     | Primary use                                                                        |
|----------------------------------------------|------------------------------------------------------------------------------------|
| Subscriber's Human Board of Record           | Understanding what the bench does and what fiduciary obligations the Board retains |
| Outside securities counsel                   | Disclosure-document preparation; Wells / SEC inquiry response; Caremark defense    |
| Outside auditor                              | PCAOB AS 2201 / AS 2405 understanding of the control environment                   |
| SEC or other regulator                       | Inquiry-response dossier; comment-letter response; Wells submission                |
| Subscriber operating staff                   | Day-to-day operating reference                                                     |
| The principal (single-principal subscribers) | Personal operating reference for fiduciary functions                               |

Modification: as Layer 1 (constitutional) and Layer 2 (procedural) sources change, this manual is updated by Bill with HBR notification, not authorization (Layer 3 is descriptive). Material structural changes to the manual itself (e.g., adding a new Part) are Gate category \#37 BR.

*This manual is the integrated reference for a system in which autonomous AI agents execute substantial portions of executive functions for U.S. public-company subscriber issuers. The agents do not hold fiduciary capacity. Every material action passes through the Governance Gate, where the Human Board of Record records authorization. Every agent action is captured in a hash-chained, WORM-archived audit trail forming the operational defense against derivative claims, regulatory inquiries, and litigation discovery. The eight agents are constrained by a pluralist Western-canon ethics framework with domain-weighted tradition application and explicit collision-resolution. The bench's purpose is to make U.S. public-company executive-function staffing accessible, auditable, and defensible. The 28 canonical content files (19 constitutional + 5 procedural + 3 technical + 1 reference) together with the 7 wiki section hubs collectively specify every aspect of that operation; this manual is the readable map.*
